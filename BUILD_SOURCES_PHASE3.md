# Phase 3 build sources

## jaudiotagger 3.0.1

Maven Central artifact: https://central.sonatype.com/artifact/net.jthink/jaudiotagger/3.0.1

Verified coordinates: `net.jthink:jaudiotagger:3.0.1`. Maven Central describes it as a Java library for editing audio tag information and lists the project URL/source control and LGPL license.

Official project page: https://www.jthink.net/jaudiotagger/

The official page states that jaudiotagger supports MP3, MP4/M4A, Ogg Vorbis, FLAC, WAV, AIF, DSF and WMA, and that it is available under the LGPL. Phase 3 uses it only for metadata/tag reading; audio decoding and spectrum analysis remain deferred to Phase 8.
